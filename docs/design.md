# Интерфейс гостя — часть «Штиля»

16 октября 2026. Исходная версия: `33226c2`.

Дашборд и гостевой сайт выполняют разные задачи. Дашборд нужен для сравнения метрик; здесь гость должен быстро найти сотрудника, отсканировать код и оценить визит. Общими остаются морская палитра, Prata/Golos Text, знак волн, поверхности, поля, светлая/тёмная темы и спокойное движение.

## Решения

| Прежняя проблема | Изменение |
| --- | --- |
| Форма жила в отдельной визуальной системе с большим встроенным CSS | Общие токены и stylesheet для обеих страниц |
| Карточки скрывались за краями карусели, хотя автопрокрутка имела нулевую скорость и оставляла JS-цикл | Обычная адаптивная сетка; все сотрудники доступны без горизонтального поиска |
| QR на круглом поле не оставлял полноценного белого пространства у углов | Квадратное белое поле с отступом 24 px и исходным canvas 256×256 |
| Генерация QR зависела от внешнего CDN | Локальный vendor с прежней версией генератора и лицензией |
| При возврате/смене экрана фокус оставался без управления | Скрытые экраны удалены из tab-порядка; заголовок и выбранная карточка получают фокус |
| Автовозврат нельзя было продлить | Кнопка «Ещё 20 секунд», компактный вид на низком экране |
| Сеть могла упасть, а finally всё равно показывал «Отправлено» | Ошибка сохраняет форму и допускает повтор; результат не изображает подтверждение записи в Sheets |
| Шаблон имени сотрудника использовал innerHTML | Внешние имена, идентификаторы и тексты выводятся через textContent |
| Крупное вступление на телефоне отодвигало оценку | В мобильной форме сокращены вводный текст и повторяющиеся заголовки |

## Движение

Фон — несколько SVG-слоёв с покачиванием и повторяющейся пенной линией. Декоративный слой имеет `aria-hidden` и `pointer-events:none`. В скрытой вкладке анимации приостанавливаются. Fade запускается CSS, контент не остаётся скрытым при сбое приложения. Смена темы меняет цвета за 550 мс; первый кадр сразу использует выбранную палитру. Пауза и системный reduced motion отключают визуальные переходы. Сервисный таймер продолжает отсчитывать реальное время.

## Проверка и ограничения

Форматы событий сопоставлены с исходным кодом. Список сотрудников прочитан из действующего источника без изменений. Записи в backend в автоматических тестах подменены; настоящий тестовый отзыв не отправлялся. QR декодируется библиотекой jsQR в браузерном сценарии, проверены исходный маршрут и staff-параметр. Автоматический контраст и семантика проверены axe в обеих темах.

Серверный код Google Apps Script отсутствует в репозитории, поэтому клиент не доказывает сохранение строки и не меняет модель доступа к таблицам. Дедупликация отзывов на сервере, подтверждённый CORS-ответ и закрытые источники — возможные отдельные задачи. Safari/Firefox, физические камеры телефонов и печатные QR не проверялись.
